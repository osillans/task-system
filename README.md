# Task System

Консольна система виконання завдань на Java.

Система виконує серію завдань, виводить результат кожного, а перед виходом друкує зведену статистику.

## Як це працює

Параметри завдання — це **вхідне значення** та **перелік обробників**. Їх можна ввести за запитом системи або передати з командного рядка. Система має словник доступних обробників. Під час виконання завдання вхідне значення подається на вхід кожному з обробників. Результати обробників одного завдання консолідуються визначеною функцією (за замовчуванням — складання). Це значення і є результатом завдання.

## Архітектура

Система складається з двох частин, що обмінюються інформацією: параметри передаються в один бік, результати повертаються у відповідь.

```
Користувач --- серія завдань ---------> UserInterface --- параметри ---------> Executor
Користувач <-- результат кожного ------ UserInterface <-- набір результатів --- Executor
```

| Файл | Призначення |
|------|-------------|
| `Executor.java` | Виконавча частина: словник обробників, застосування обробників до значення |
| `UserInterface.java` | Інтерфейсна частина: введення, консолідація результатів, виведення, статистика |
| `Handler.java` | Інтерфейс обробника (число -> число) |
| `Task.java` | Параметри завдання та розбір введеного тексту |
| `Consolidation.java` | Функції консолідації результатів |
| `Statistics.java` | Збір зведеної статистики |
| `Main.java` | Точка входу, параметри командного рядка |
| `run.bat` | Збірка та запуск |

## Обробники

| Назва | Дія |
|-------|-----|
| `inc` | x + 1 |
| `dec` | x - 1 |
| `double` | x * 2 |
| `half` | x / 2 |
| `square` | x в квадраті |
| `cube` | x в кубі |
| `neg` | -x |
| `abs` | модуль x |
| `sqrt` | квадратний корінь (x >= 0) |
| `inv` | 1 / x (x != 0) |

Новий обробник додається в `Executor` одним рядком:

```java
register("назва", "опис", x -> /* обчислення */);
```

| Параметр | Значення |
|----------|----------|
| `-t`, `--task` | завдання у форматі `значення: обробник1, обробник2`; можна вказувати кілька разів |
| `-c`, `--consolidate` | функція консолідації: `sum`, `product`, `max`, `min`, `mean` |
| `-l`, `--list` | показати словник обробників |
| `-h`, `--help` | довідка |
